8. **Trang Liên hệ & Tiếp nhận Đầu tư**:

   - Bản đồ trụ sở 35 Hùng Vương, Ba Đình, Hà Nội.
   - Tự động kiểm tra dữ liệu và phản hồi thông báo xác nhận gửi về email quản trị.

### 2. Cách Sử Dụng & Mở Trang Web

- **Cách 1 (Nhanh nhất)**: Nhấp đúp vào tệp `Mo_Trang_Web.bat` hoặc mở tệp `index.html` bằng bất kỳ trình duyệt nào (Chrome, Edge, Firefox).
- **Cách 2 (Khởi chạy Local Server bằng Python)**:
  ```bash
  cd "D:\New folder\Giới thiệu công ty"
  python -m http.server 8080
  ```
  Sau đó mở trình duyệt và truy cập `http://localhost:8080`.
